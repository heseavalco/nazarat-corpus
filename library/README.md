# کتابخانهٔ سوابق شرعی شورای نگهبان (پروژهٔ گروه مشورتی فقهی)

ساخته‌شده از برداشت کامل «سامانهٔ جامع نظرات شورای نگهبان» (nazarat.ccri.ac.ir)، ۱۴۰۵/۰۶/۲۲.

| فایل | محتوا |
|---|---|
| `precedents.jsonl.gz` | ۳٬۴۵۵ واحد ایراد/نظر شرعی شورای نگهبان با برچسب‌ها: `hukm` (خلاف شرع / اطلاق خلاف شرع / ابهام / عدم مغایرت / ارجاعی / قانون اساسی / سایر)، `onvan_feqhi` (عنوان فقهی)، `mozu` (۱۲ شاخه)، `mekanism`، `ebarat` (عین عبارت)، `mahal` (محل ایراد)، `letter_no` و `letter_date` (شمارهٔ نامه و تاریخ)، `title` (مصوبه)، `text` (متن کامل واحد) |
| `units_sharia.jsonl.gz` / `units_all.jsonl.gz` | واحدهای خام (پیش از برچسب) — همهٔ بندهای نامه‌ها |
| `gc_letters_sharia.jsonl.gz` | متن کامل ۶٬۰۷۱ نامهٔ شورا با محتوای شرعی |
| `gc_letters_all.jsonl.gz` | متن کامل همهٔ ۷٬۵۷۰ نامهٔ «نظر شورای نگهبان» |
| `majma_fiqhi.jsonl.gz` | ۱٬۲۳۸ نظر/گزارش مجمع مشورتی فقهی (استدلال‌ها و آرا) — هنوز برچسب نخورده |
| `find_precedent.py` | جست‌وجو: `python3 find_precedent.py "ربا" "تأخیر"` ، `--regex` ، `--hukm` ، `--mozu` ، `--full` |
| `شاخص سوابق شرعی شورای نگهبان.md` | شاخص فشرده (شاخه → باب فقهی → شمار و نمونه‌ها) |
| `build_units.py` ، `LABELING_INSTRUCTIONS.md` | بازسازی واحدها از پیکرهٔ متنی و دستور برچسب‌گذاری |

پیکرهٔ متنی خام (`nazarat_text.zip`) و PDFها در Release «corpus» همین مخزن هستند.
